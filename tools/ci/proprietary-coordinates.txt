# Maven coordinate prefixes F-Droid will not accept.
#
# F-Droid builds only free software, and a dependency from this list gets the
# whole app rejected. The rejection arrives weeks later, by email, long after
# the pull request that caused it was merged, which is why this is checked here
# instead.
#
# One prefix per line, matched against the start of `group:artifact`. Blank
# lines and lines starting with # are ignored.
#
# To allow something that matches a prefix but is genuinely free, add it to
# tools/ci/proprietary-allowed.txt rather than weakening a line here.
